# Print geometry in pixel-native tools

Screen canvas tools have no inches, no bleed, no fold logic. All of it has to be carried as explicit pixel math and drawn guides. The rules below keep a px-native artboard faithful to a physical piece.

## The base math

Work at 300 ppi. One inch = 300 px, so every physical dimension converts exactly:

- artboard size = **bleed size**, not trim size. Standard bleed is 0.125" per edge, so an 8.5×11" piece is (8.75 × 300) × (11.25 × 300) = 2625 × 3375 px.
- trim = artboard inset by the bleed (37.5 px per edge at 300 ppi, use 37 or 38 consistently, or work at 600 ppi if the half-pixel bothers you).
- safe margin = trim inset by at least 0.125" more. Nothing that matters (type, logos, page furniture) outside the safe box.

Draw all three as explicit guide rectangles or frames on the board, named `bleed` / `trim` / `safe`, locked if the tool allows. Anything that should print to the edge must extend to the bleed edge, not stop at trim.

## Folds

- Never derive fold positions by dividing the width evenly. Folded pieces need **fold allowances**: any panel that folds into another must be slightly narrower (typically 1/32" to 3/32" per roll-in) or the piece buckles.
- Get the vendor's fold template for the exact piece and size, they publish these as PDFs with exact panel widths. Treat those widths as absolute values and convert each to px; do not rescale a template proportionally to a different overall size, re-derive from the allowances instead.
- The two sides of a folded piece are mirrored: the panel order on side 2 reverses side 1. Compute each side's fold positions separately and draw them as named guides with their inch values in the name (e.g. `fold @ 3.90625"`).
- Keep type and critical art off the creases. Give folds the same clearance as a safe margin unless the design deliberately crosses a fold, and if it does, check the crossing at the first opening stage, not just fully flat.
- Build a fold-stage strip: small cards showing the piece at each opening state (folded front, first opening, fully open, back). Clients and printers both read the piece this way, and it catches panel-order mistakes that a flat spread hides.

## Export

- Export at artboard (bleed) size, 1:1, into the approval/mockup pipeline.
- Final print files are rebuilt in a print-capable tool at true physical size, with colors from the recorded recipes (see the main skill) and marks/bleed generated by that tool, not by the canvas export.

# practices: paper

paper canvas and paper mcp mechanics, graded by `rules.md`. read this before
the first paper call in a session. most of these failures report success,
so the row is the only warning.

## defaults

| topic | rule | evidence |
|---|---|---|
| bulk resize | set width and height in a dedicated update_styles call with no other keys, then check one node with get_node_info | 2026-08-19 slot collapse; clean on a 13-frame resize the same week |
| cross-parent clones | after any duplicate_nodes into a different parent, set left and top explicitly. clones land at the parent origin or at stale source-relative offsets | 2026-08-19: 39 clones at 0,0; 22 clean repositions the same day |
| svg edits | for any structural or geometry edit, replace the whole svg node with write_html mode:replace (get_jsx, edit, replace). replacing an SVGVisualElement child mints a junk Rectangle and deletes the original, and replacing a `<g>` inside an svg with a bare svg fragment parses as an invisible Frame. a pure restyle (fill, stroke) can take update_styles directly on the path node, but the original attribute stays behind for code ports, so replace the whole `<svg>` when the result will be ported (`practices/paper.md`, svg retints) | 2026-07-09, a delete and full-svg rewrite round; 2026-08-20; 4 clean replaces 2026-08-21 |
| clone internals | before setting left or top on any child of (or extracted from) a duplicated composite, read its computed styles and zero any inherited translate. left and top add to translate silently, including -50% self-centering and static px offsets | 2026-08-19; 2026-08-23 an inherited 725px translate put 3 placements off-panel |
| print pdf export | the page declares 1px = 0.75pt (a 4875px frame claims about 50.8in), and the scale parameter is ignored for pdf. text exports as Type3 vector glyphs, so "no embedded fonts" scans are a false alarm; art exports as JPEG image XObjects. for true print size, post-scale with pypdf and reset MediaBox, TrimBox, and BleedBox, which stays vector and lossless | 2026-08-21; clean again 2026-08-24 |
| empty screenshots | an empty get_screenshot with no error has two causes. a tall artboard (about 4000px and up): capture child sections instead. a dead renderer for the whole file (export says "No DOM element", the tree reports 0×0 dims): edits still apply, so verify with get_tree_summary and get_node_info, ask the operator to refresh the paper tab for visual checks, and stop retrying screenshots | 2026-08-19, 2026-08-21, 2026-08-25; an export probe confirmed the dead renderer in one call |
| label rows | a wrapper whose children are all text spans flattens into one Text node when the wrapper is absolutely or statically positioned; flex-flow wrappers keep every span. build label rows as a flex row with fixed-width slots | 2026-08-18, 2026-08-25, 2026-09-01: bit twice when positioned, clean twice as flex rows |
| small asset ingestion | write_html a temporary `<img src="data:image/png;base64,...">`, read the hosted file-assets url from its computed styles, point real nodes at that url (an inline `background-image:url(hosted)` also works), then delete the temporary node. keep payloads under about 12KB of base64 (17KB drops silently); downres and re-dither to fit. uploads can also truncate silently, so curl the hosted url and compare it to the local file with `magick compare -metric AE` before using it, and re-ingest on a mismatch. comma-separated background urls layer, first on top | 2026-08-21; 2026-08-24: three clean ingests, and one truncation caught at the cost of a debug round |
| large asset ingestion | `<img src="paper-asset:///abs/path.png">` (png or jpg) in write_html hosts large files byte-identical (270KB png and 716KB jpg, AE 0). use it for anything over a few KB, and still curl and compare once per batch | 2026-09-03 (7 of 7 clean); 2026-09-07 (3 of 3 clean) |
| freeform frames | the mcp cannot switch a frame to paper's no-layout mode (what the operator calls "no autolayout"; display:block, and create_artboard with display:block, are both ignored: the exported JSX looks right while the inspector and layer tree still show autolayout). to get a freeform frame, duplicate_nodes an existing freeform frame (its computed styles have no `display` key) into the page root, delete its children, and resize it. otherwise build flat (an artboard with leaf nodes only) so the operator flips one toggle per frame; never spend a session converting. write_html drops an empty `<div>` (createdNodes comes back empty), so give an empty container a throwaway `<span>` and delete it after | 2026-09-03 a wasted conversion pass; 2026-09-06 clean; 2026-09-07 clone workaround |
| text metrics | percentage line-heights render rounded up to whole px per line (12px × 120% = 15, 10px = 12, 8px = 10; at 110%, 12px = 14 and 10px = 11). budget canvas heights with ceil(size × leading), and when porting a paper page to html, encode those rounded px line-heights, or each 12px line lands 0.6px short and the page drifts. write_html text with a width and text-align mints a flex frame wrapper: write the plain leaf, then update_styles {width, textAlign, whiteSpace: "pre-wrap"} | 2026-09-09, a close-box overflow; 2026-09-17, an html port drifted 6.8% until the line-heights were encoded |

## experiments

| topic | rule | evidence | recheck when |
|---|---|---|---|
| tool arguments | argument shapes differ per tool and only error messages reveal them: get_tree_summary takes `nodeId`, update_styles takes `updates[].nodeIds`, duplicate_nodes takes `nodes[].id`, rename_nodes takes `updates[]`. check the schema before a first call | 2026-08-21, four retries | next session with an unfamiliar paper tool |
| re-ingesting assets | a changed file written under the same local path returns the old hosted asset, because the cache keys on the path. ingest every regenerated image under a new filename. the tell: computed styles still show the previous url, and curl plus compare gives AE above 0 | 2026-09-04, an old photo survived an approval round | next paper-asset re-ingest |
| freeform reparenting | move_nodes into a different freeform parent does not keep rendered position, and batches land scrambled (23 pieces piled at the top-left). it also drops a flex child's size intents (pills stretched to about 1300px tall) and re-anchors to the parent's padding box, so children paint over its hairline. before a freeform reparent, read rendered x and y with get_children on the old parent. after moving, re-pin every node with position:absolute, left, top, and translate:0px 0px, pin width and height explicitly, and add the parent's border width to each offset. flow-to-flow reparents and same-parent reorders keep their positions; for order, see (`practices/paper.md`, child order) | 2026-07-28, two builders each lost a fix round; 2026-08-23 one scrambled panel; 2026-09-17 16 flow reparents clean | next freeform reparent batch |
| frames written with children | a bare write_html div becomes a flex frame, and children that arrive with it lose position:absolute, whether they are clones dropped in or absolute children in the same write_html call. create the frame first and insert children in a second call, or set position:absolute on every child after. same-parent duplicates keep their absolute positioning | 2026-08-18; 2026-09-03 one blank render | next whole-frame write_html |
| mirroring | update_styles `transform: scaleX(-1)` and `scale: -1 1` are silently dropped on background-image rects. bake the mirror into the asset with `magick -flop` and re-ingest | 2026-08-24, two failed attempts | next mirror request |
| anatomy anchors | when placing geometry across sibling cards, anchor to each card's visible anatomy rect (its background or border origin), never the frame origin, because hand-built siblings can carry different internal origins. read one anatomy rect per unit first | 2026-08-19, 11 of 13 cards landed 17px off | next multi-unit placement |
| stale node ids | each write_html replace mints a new node id. a replace aimed at an old id reports success and creates the content orphaned at the page root (0,0). carry the new id forward, and treat new nodes at world 0,0 as the tell | 2026-08-25, 5 of 13 replaces orphaned; one debug round and orphan cleanup | next multi-round replace session |
| clones into flex columns | a hug-width chip or frame duplicated into a flex-column parent stretches to full width, so set alignSelf:flex-start in the same pass (flex-row parents are safe). clones into a flex-column artboard land position:absolute with the source's left and top, and position:static alone does not release them: set position:static, left:0, top:0, and translate:0px 0px in one update | 2026-08-25, bit three times and cost two fix rounds; 2026-09-07, one debug round per builder and a 4-board height drift | next clone into a flex column |
| shallow clones | x-paper-clone inside write_html shallow-clones a multi-child flex row, and only the first cell survives. deep-copy composites with duplicate_nodes. x-paper-clone is fine for leaf frames such as logo svgs, and x-paper-clone into a new wrapper, then deleting the original and moving it in with move_nodes, is a clean way to wrap an existing node | 2026-09-01, one rebuild round; 2026-09-08 wrap recipe | next clone of a composite |
| node search | find_nodes cannot search layer names: its filters take styleName and styleValue, and textValue matches text content. locate nodes by a known id, get_tree_summary, or get_children | 2026-08-19, two failed calls | next node search |
| cross-file copies | duplicate_nodes cannot cross files. a parentId in another file is ignored and the clone lands orphaned at the source page root, reported as success. move content between files with get_jsx and write_html, or have the operator copy and paste in the app, and delete the orphan at once | 2026-08-21, a stray orphan frame mid-session | next cross-file transfer |
| precision svg | paper's svg renderer mis-parses long stroked paths with chained relative movetos, so a qr code (segno's shorthand output) shifts every later row by 2 modules after the first non-uniform `m-N 1`. screenshots look right while the export fails to decode. for machine-readable or precision art, write filled subpaths with absolute starts (`M{x} {y}h{w}v{h}h-{w}z` per run) and verify by exporting and decoding, never by eye | 2026-08-20, a broken qr shipped before the decode check | next generated-svg pass |
| tokens | set_tokens only updates, renames, and deletes, and every create attempt returns "Token not found" per entry; new tokens go through create_tokens, whose type enum has no duration type, so motion numbers stay in the code token file. create_tokens rejects `var(--x)` as a color ("Invalid value") only when the target doesn't exist yet: create the palette first, then the aliasing roles in a second call. set_tokens with newName renames a token and every binding follows, so a global re-leading is: rename the old token to a data token, create the new one under the old name, and rebind the smaller copy set. `var(--token)` binds for font family, weight, size, line-height, letter-spacing, color, background, padding, and radius, but the `border: var(--w) solid var(--c)` shorthand is dropped, so use longhand: border-width in px, border-style, and border-color as `var()`. text nodes drop borders; put rules on a wrapper frame | 2026-08-25, a 47-entry batch bounced; 2026-09-08, a 52-entry batch bounced plus a probe round; 2026-09-22, 18 aliases bound clean | next token-authoring session |
| scaling groups | update_styles drops `transform: scale()` and the `scale` property, and only rotate survives. to resize a composed group, change the artboard density so the source fits, or restyle leaf nodes | 2026-09-06, one debug round and a full re-density of two artboards | next resize-a-group request |
| child order | duplicate_nodes into a flex-flow parent does not reliably append at the end, and a move_nodes batch inside one child can flip its siblings in the grandparent row. after any duplicate into a flow parent or any regroup, check the order with get_tree_summary at depth 1 (screenshots can come back empty or stale) and fix it with move_nodes | 2026-08-25, caught by a tree check, one move fix; 2026-09-23 a regroup swapped a panel and a copy column | next duplicate into a flow parent |
| pdf assembler errors | "Error assembling PDF page" on every node, including a bare rectangle and a previously exported artboard, on both `export` and `export_combined_pdf`, is transient app state, not content, and png export still works. probe one bare rect and one known-good artboard in a single call. then retry later or switch pages, then restart paper, then check the build | 2026-09-07, one 12-node bisect call; clean the next day with no change | next pdf export failure |
| pdf scale drift | an artboard child positioned with left:50% or calc(50%) plus translate:-50%, whose extent passes the frame edge, makes the pdf export draw the whole artboard scaled down; a calc(50%)-top child can spill onto a second page. export reports success and png is unaffected. pin every percent-positioned direct child of the artboard, or of full-width bands, with px left and top and translate:0px 0px; nested children inside self-contained frames are fine. verify by rendering the pdf at 96dpi and comparing it to the 1x png (`compare -fuzz 20% -metric AE`, under 4% differing is edge noise); the tell is a content stream whose first filled rect (`.1569 .1569 .1569 rg … re f`, paper's #282828 canvas grey) isn't the artboard size, or more than one page | 2026-09-11, about an hour of bisecting | next pdf export |
| opacity on composites | opacity below 1 on a frame with thousands of children renders the whole artboard black. knock a group back with a full-size rgba overlay rect above it | 2026-09-07, one blank render round | next opacity request |
| fixed-width pre text | a text node with `white-space: pre` stays hug-width, and width settings are accepted with no ignoredStyles and silently not applied. use white-space:pre-wrap, or a sized flex wrapper, when alignment or wrapping depends on the box | 2026-09-07, two wasted width calls | next fixed-width pre text |
| freeform to flex | update_styles {display:flex, flexDirection, gap, height:auto} converts a freeform frame, and its children flow once set to position:static, left:0, top:0, translate:0px 0px. the reverse is blocked (`practices/paper.md`, freeform frames). flexWrap:wrap on a flex row is honored | 2026-09-07; 2026-09-11, three pages converted in one pass with no hand conversion | next layout conversion |
| positioned image slots | in write_html, inline left and top are dropped unless position:absolute is in the same inline style, and write_html resets transform-origin to 50% 50%. for a rotated background-image child, write position:absolute, left, top, and rotate inline, then run one update_styles {transformOrigin: "0% 0%"}. the symptom is a slot showing bare background color | 2026-09-14, six blank art slots and two debug rounds | next background-image slot |
| positioning context | update_styles position:relative is ignored on frames, which already position their children. absolute children with right and bottom offsets work | 2026-09-08 | next positioned child |
| screenshots past the edge | a flow child below a fixed-height artboard's bottom edge screenshots solid black. set the artboard to height:fit-content first | 2026-09-16, one round | next build past a fixed height |
| stuck padding | a frame carrying the paddingInline shorthand (often left by write_html `padding-left`/`padding-right` pairs) ignores every later padding update, including paddingLeft, paddingRight, paddingInline, and padding, reported as success. write a fresh wrapper frame with a throwaway child, move the children in, and delete the stuck frame | 2026-09-22, four failed updates | next padding change on a ported frame |
| failed jsx reads | get_jsx can fail on whole artboards ("Unterminated string"). read structure with get_tree_summary, get_computed_styles, and get_children instead | 2026-08-26 | next get_jsx failure |
| inspector state | the mcp cannot read paper's inspector state, such as a frame's layout mode; only a browser connection to the paper tab can. if the browser isn't connected, ask the operator before a conversion pass | 2026-09-03, one wasted pass | next layout-mode question |
| svg markers | css variables don't resolve inside svg `<marker>` defs: marker fills silently render default black while stroked paths resolve fine. use literal hex inside marker defs | 2026-07-09, a 10-svg rewrite round | next diagram with arrowheads |
| rotation and patterns | css rotation on a frame doesn't propagate to its children (the border tilts, the contents stay axis-aligned), and repeating-gradient backgrounds can render empty. build tilts and overlays as artboard-level absolute elements, and textures as explicit svg | 2026-07-09, a rebuild round on a 1.2° tilt and a dropped scanline pattern | next tilt or texture |
| operator-editable artifacts | when the operator will hand-edit a frame, build it from native elements: rectangles as plain divs (they become Rectangle nodes), never svg rects; no full-canvas invisible wrapper frames, which capture selection; groups placed flat in the artboard; and write_html on a single line, because whitespace between tags becomes empty Text nodes. use svg only for genuinely non-rectangular shapes | 2026-07-10, three rebuild rounds of 10 frames after the operator couldn't move svg pieces | next build meant for operator editing |
| tinted structure | `color-mix()` doesn't resolve in write_html or update_styles: a token at alpha silently collapses to `#00000000`, while every plain property around it applies. bind alpha as `opacity` on a token-colored element, or drop the tint. never fall back to a hand-mixed hex, which ships a second undeclared ink. probe one write and read back its computed styles before building on a tint | 2026-07-26, caught by a probe after an earlier pass had shipped a hand-mixed hex | next build with tinted structure |
| detached nodes | during a batch of position or style updates on a freeform board, a node can detach from its artboard (parentId and artboardId go null). get_node_info still reports its size and world coordinates, but it stops rendering, and move_nodes on it returns index -1 with the node absent from affectedParents. check the parent's childIds after any bulk reposition, and rebuild a detached node instead of re-parenting it | 2026-07-26, a panel outline vanished after a 21-node shift | next bulk reposition |
| svg retints | a token restyle of an svg child through update_styles sets an inline style but leaves the original `stroke` or `fill` attribute, so get_jsx exports both and a code port reads the stale value. after retinting an svg that will be ported to code, replace the whole `<svg>` so the attributes match | 2026-07-26, three retinted crosses kept a stale stroke | next svg retint |
| full-artboard duplicates | duplicate_nodes on a full artboard returns a descendantIdMap too large for context, so it lands in a saved file. grep that file for the ids you need instead of reading it | 2026-08-23, no time lost once the saved file was grepped | next full-artboard duplicate |
